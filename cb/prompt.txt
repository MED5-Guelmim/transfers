══════════════════════════════════════════
 هيكل قاعدة البيانات (النماذج)
══════════════════════════════════════════

1. نموذج Academy (الأكاديمية):
   - id, name (اسم الأكاديمية), city (المدينة)
   - hotel (اسم الفندق الذي تقيم فيه)

2. نموذج Team (الفريق):
   - id
   - academy_id (FK → Academy)
   - gender: ENUM('ذكور', 'إناث')
   - category: ENUM('U18', 'U15', 'U18_sport_study', 'U15_sport_study')
     (أي: أقل من 18، أقل من 15، أقل من 18 رياضة+دراسة، أقل من 15 رياضة+دراسة)
   - day1_status: ENUM('active', 'eliminated') — الحالة في اليوم الأول
   - day2_status: ENUM('active', 'eliminated') — الحالة في اليوم الثاني
   - UNIQUE constraint على (academy_id + gender + category)
     [يعني كل أكاديمية لها فريق واحد فقط لكل فئة]

3. نموذج Vehicle (وسيلة النقل):
   - id, name (اسم/رقم العربة)
   - type: ENUM('small', 'large')
     → small: طاقة 2 فريق كحد أقصى
     → large: طاقة 4 فرق كحد أقصى
   - ownership: ENUM('academy', 'public')
     → academy: خاصة بأكاديمية معينة
     → public: متاحة للجميع
   - academy_id (FK → Academy, nullable — null إذا كانت عامة)
   - can_return: Boolean (هل يمكنها الذهاب والإياب؟ افتراضي True)

4. نموذج Trip (الرحلة — ناتج الخوارزمية):
   - id
   - vehicle_id (FK → Vehicle)
   - day: INTEGER (1 أو 2)
   - direction: ENUM('go', 'return')
   - trip_order: INTEGER (ترتيب الرحلة في ذلك اليوم)
   - teams: Many-to-Many مع Team عبر جدول وسيط trip_teams

══════════════════════════════════════════
 صفحات التطبيق
══════════════════════════════════════════

الصفحة 1 — لوحة التحكم (/):
- إحصائيات سريعة: عدد الأكاديميات، الفرق النشطة، وسائل النقل
- أزرار سريعة للصفحات الأخرى
- تصميم بطاقات (cards) جميل مع ألوان مميزة

الصفحة 2 — إدارة الأكاديميات (/academies):
- عرض جميع الأكاديميات في جدول
- إضافة أكاديمية جديدة (اسم + مدينة + فندق)
- تعديل وحذف
- عند النقر على أكاديمية → يظهر تفصيل فرقها

الصفحة 3 — إدارة الأكاديمية وفرقها (/academy/<id>):
- معلومات الأكاديمية (اسم، فندق، مدينة)
- قسم "الفرق": عرض بشكل بطاقات مصنفة:
  ┌─────────────────────────────┐
  │         ذكور                │
  │  [ U18 ] [ U15 ]            │
  │  [ U18 رياضة+دراسة ]        │
  │  [ U15 رياضة+دراسة ]        │
  │         إناث                │
  │  [ U18 ] [ U15 ]            │
  │  [ U18 رياضة+دراسة ]        │
  │  [ U15 رياضة+دراسة ]        │
  └─────────────────────────────┘
- كل فريق عليه: زر تفعيل/إقصاء (toggle) لليوم 1 واليوم 2
- الفرق غير الموجودة قابلة للإضافة بنقرة واحدة
- قسم "النقل الخاص": عرض عربات هذه الأكاديمية مع إضافة/حذف

الصفحة 4 — إدارة وسائل النقل (/vehicles):
- جدول كل وسائل النقل مع نوعها وملكيتها
- إضافة عربة جديدة (اسم + نوع + ملكية + إذا خاصة: اختيار الأكاديمية)
- تعديل وحذف

الصفحة 5 — توزيع النقل (/distribution):
- اختيار اليوم (1 أو 2)
- زر "توليد التوزيع تلقائياً"
- الخوارزمية (مشروحة أدناه)
- عرض النتيجة في جداول واضحة:
  - لكل عربة: قائمة رحلاتها (ذهاب ثم إياب)
  - لكل رحلة: الفرق التي تحملها

الصفحة 6 — حالة الفرق (/teams_status):
- عرض كل الأكاديميات
- عند النقر على أكاديمية: تُفتح accordion وتظهر فرقها
- لكل فريق: toggle سريع للحالة (نشط/مقصى) لليوم 1 و 2
- تصميم جميل: الفرق النشطة باللون الأخضر، المقصاة باللون الأحمر

الصفحة 7 — التقارير والتصدير (/reports):
- اختيار: تقرير أكاديمية معينة أو تقرير عام
- اختيار اليوم (1 أو 2 أو كلاهما)
- معاينة في الصفحة بتصميم جميل
- زر "تصدير PDF"
- زر "تصدير Excel"

دالة assign_teams_to_vehicles(teams, vehicles):
    capacity = {'small': 2, 'large': 4}
    current_load = {v.id: 0 for v in vehicles}
    for team in teams:
        for vehicle in sorted(vehicles, key=lambda v: current_load[v.id]):
            if current_load[vehicle.id] < capacity[vehicle.type]:
                assign team to vehicle
                current_load[vehicle.id] += 1
                break
